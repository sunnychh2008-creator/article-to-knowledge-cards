# 上线前检查清单

这份清单是我们团队两年来踩坑总结出来的，每次发版前逐条过一遍。

## 功能

- 主流程在预发环境完整跑通，不只是点通一个按钮
- 所有新增接口有明确的失败返回，不存在"没返回就是成功"的情况
- 权限校验覆盖到每一个新增接口，不能只在前端隐藏按钮

## 数据

- 新增字段有默认值，能兼容历史数据
- 涉及金额的字段精度统一，不用 float
- 有回滚方案，且回滚脚本已经实际跑过一遍，不是"理论上可回滚"

## 监控

- 新增的定时任务有执行结果日志，失败要告警
- 关键路径的耗时埋点已上报，不上线后才发现没人看过监控
- 日志不打印用户手机号、身份证等敏感字段

## 沟通

- 变更内容同步给客服和运营，涉及用户可见变化
- 如果影响接口，通知下游调用方并给出下线时间
