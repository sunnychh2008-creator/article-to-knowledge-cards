# 测试说明

本目录记录 make-knowledge-cards Skill 的测试过程，用于验证规则在不同文风下的表现，并保留每次迭代发现的问题。

## 重要声明：样例文本来源

`samples/` 下的四篇文章**均为测试时为覆盖不同文风而编写的虚构文本**，不来自任何出版物、官方网站或第三方来源，也不代表任何真实机构、作者或产品的观点。

| 文件 | 文风类型 | 覆盖的测试点 |
| --- | --- | --- |
| `01-longform.md` | 技术长文 | 4 个小节、含现象与判断标准两层，验证同小节拆多卡 |
| `02-short.md` | 短评（约 150 字） | 信息量不足时能否压到 3 张而不硬凑 |
| `03-checklist.md` | 分组清单 | 「可迁移原则 vs 一次性动作」的筛选判据 |
| `04-argumentative.md` | 单论点论证 | 自问自答结构、设问句是否会误当知识点 |

文中出现的公司名、技术名词均为虚构场景的通用示例，不涉及真实产品评价。

## result 文件

`0*-*-result.md` 记录每次测试的实际产出与发现的问题。文件分两部分：前半是按 Skill 规则生成的卡片正文，后半是自检结果与问题清单。

**问题清单是本目录的主要价值** —— 规则里的每一条判据都对应一个真实踩过的坑：

- 照抄小节标题当卡片标题
- 自问自答和过渡句被误当知识点
- 作者个人经历被独立成卡
- 清单里的一次性动作挤占卡片名额
- 「简明解释」栏补充了原文没有的因果机制
- 原文例子质量差时硬撑

## 注意

`quick_validate.py` 只校验 SKILL.md 的 frontmatter 结构，**不检查规则内容质量**。规则是否有效，只能靠本目录的样例人工过一遍。
